Please enjoy this talk “UBS Knowledge Graph: Building a Connected Data Catalog,” from the Knowledge Graph Conference 2023 given by Gregor Wobbe, Head of Data Architecture at UBS.

Talk description:

UBS is building a new firm-wide data platform that will empower every employee to harness AI, data, and analytics to gain valuable insights for its financial services clients. Knowledge graph technology plays a key role in this next-generation data ecosystem by helping to discover, understand, trust, and use relevant data assets.

Technical topics covered: 

  • Data Management
  • Artificial Intelligence
  • Graph Technology
  • Data Architecture
